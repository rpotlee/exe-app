A list row is 44pt minimum, one concept per row, separators inset past the leading glyph.

**Native counterpart.** SwiftUI `List` with `.listStyle(.insetGrouped)`; `Toggle`-style checkbox via `Label`.

**Rules.**
- Checking a raw capture only completes the capture. Do not imply task completion or AI review.
- Title in `body`, subtitle in `subhead` + `label-secondary`.
- Trailing chevron means navigation; trailing text is metadata.
- Support swipe actions; never hide the only path to an action behind a swipe.
