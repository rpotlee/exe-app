Chips label status with a glyph, a word and a soft tint.

**Native counterpart.** Custom; use `Label` with SF Symbols and `Capsule` backgrounds.

**Rules.**
- Red = blocker only. Orange = decision needed/stale. Green = ready/done. Indigo = AI. Blue = interactive/selected. One color, one meaning.
- Never use a chip as a button; use `Button`.
